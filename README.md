# Планировщик (MVP)

Задачи с локальными напоминаниями. React Native + Expo (SDK 58), Expo Router, TypeScript strict.
Данные хранятся на телефоне (AsyncStorage), уведомления локальные (expo-notifications).

## Запуск на Windows (PowerShell)

```powershell
cd путь\к\planner
npm install
npx expo start
```

Затем отсканируйте QR-код в приложении Expo Go (iPhone: камерой; Android: из самого Expo Go).
Телефон и ноутбук должны быть в одной Wi-Fi сети. Если не подключается: `npx expo start --tunnel`.
Сброс кэша: `npx expo start -c`.

## Проверка по критериям приёмки

1. «+» → задача → кнопка «Поставить на 3 минуты вперёд» → Сохранить → заблокировать телефон → придёт уведомление.
2. Откройте задачу, измените время → старое уведомление не придёт, новое придёт в новое время.
3. Удалите задачу → уведомление не придёт.
4. Повтор «Ежедневно» → уведомление приходит каждый день в это время.
5. Закройте приложение полностью и откройте снова → задачи на месте.
6. Запретите уведомления в настройках телефона → приложение работает, сверху плашка с пояснением.
7. Нажмите на уведомление → откроется экран этой задачи.

## Структура

- `src/app/` — экраны (Expo Router): `(tabs)/index.tsx` «Сегодня», `(tabs)/all.tsx` «Все задачи», `task/[id].tsx` форма.
- `src/context/TasksContext.tsx` — состояние (Context + useReducer), связывает задачи и уведомления.
- `src/notifications/notifications.ts` — разрешения, канал Android, планирование и отмена.
- `src/storage/taskStorage.ts` — AsyncStorage.
- `src/utils/dates.ts` — даты, повторы, группировка.

## Повторные напоминания и звук

- В форме задачи: «Повторять напоминание, пока не выполнено» (каждые 5 / 10 / 15 / 30 минут или каждый час) и переключатель «Звук уведомлений».
- Повторные напоминания планируются заранее средствами ОС: после времени задачи придёт до 12 штук (при интервале 10 минут это около 2 часов). Отметка «выполнено», удаление или правка задачи отменяют все.
- Каждый раз, когда приложение открывают, окно повторов сдвигается вперёд, так что напоминания продолжаются «до выполнения».
- iOS хранит не больше 64 запланированных уведомлений на приложение. При большом числе задач с повторами ближайшие по времени сохраняются, остальные допланируются при открытии приложения.
- Звук: «со звуком» (стандартный сигнал телефона) или «без звука». На iOS беззвучный режим телефона (переключатель на корпусе) глушит звук всегда.
- Свои мелодии в Expo Go недоступны: их нужно упаковывать в сборку (development build).

## Принятые решения

- `dueAt` хранится как ISO в UTC, показывается в местном времени.
- Ежемесячный повтор ограничен 28-м числом.
- Отметка выполненной у повторяющейся задачи переносит её на следующее срабатывание.
- На экране «Сегодня» есть блок «Просрочено» для невыполненных задач прошлых дней.
- Android: уведомления «липкие» (не смахиваются), пока задачу не отметили выполненной, не нажали на уведомление или не удалили задачу.

## Установка на iPhone бесплатно (Sideloadly)

Файл `.github/workflows/build-ios-ipa.yml` собирает `Planner.ipa` без подписи в облаке GitHub (на бесплатном Mac).
Запуск: GitHub → вкладка Actions → «Build iOS IPA (без подписи)» → Run workflow. Готовый файл скачивается из раздела Artifacts.
Дальше его подписывает и ставит на телефон Sideloadly (бесплатный Apple ID, 7 дней действия).
